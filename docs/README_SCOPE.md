# README scope note | Nota de alcance del README

## Decisión | Decision

El README principal debe ser operativo y breve. | The main README must be operational and concise.

## Qué debe contener | What it should contain

- Propósito del laboratorio.
- Estructura principal.
- Comandos rápidos.
- Parámetros experimentales.
- Rutas de resultados, evidencias y freezes.
- Enlaces a documentación detallada.

## Qué no debe contener | What it should not contain

- Desarrollo completo de metodología.
- Justificación bibliográfica extensa.
- Discusión de resultados.
- Respuesta detallada a revisores.
- Configuración profunda de Zabbix/Wazuh.
- Interpretación del paper.

## Ubicación del detalle | Detail location

El detalle técnico vive en `docs/`. | Technical detail lives in `docs/`.
